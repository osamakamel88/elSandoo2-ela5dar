Ready for installation on ANY Windows PC from GitHub:

1. Double-click "install.bat"
   - Automatically connects to GitHub and imports latest updates.
   - Automatically installs Python 3.11, portable FFmpeg, and Visual C++ runtimes if missing.
   - Configures the environment and installs all dependencies.

2. Double-click "run.bat" to start the app at http://localhost:8501!

3. To check for new updates anytime: double-click "update.bat".
4. To test your environment anytime: double-click "check_prerequisites.bat".
